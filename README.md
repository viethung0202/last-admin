# Hula Admin

Merchant dashboard frontend for Hula.

## Stack

- Vite
- React
- TypeScript
- Tailwind CSS v4
- shadcn/Base UI

## Environment

Copy `.env.example` to `.env` if you need to override the backend URL.

```env
VITE_API_URL="http://localhost:3000"
```

## Commands

```bash
npm install
npm run dev
npm run build
```

The app is still at scaffold stage. Merchant login and product management are the next features to build.
